Save one lasting fact or preference to memory, so that later chats start already knowing it. The user sees every saved note in their memory list and can edit or delete it.

Call it the moment the user asks you to remember something, or states a standing preference, a fact about themselves, or a convention of the project that will still matter in other chats — before you go on with the task. Do not call it for the progress or plan of the current task (that is todo_update), for what can be read from the project's files, for a detail that matters only in this conversation, or for secrets, passwords and keys.

This is not AGENTS.md. Instructions and rules live in AGENTS.md and change only when the user asks to edit that file; memory_save adds one short note and never rewrites instructions or any other file.

scope — "project": true only for the project this chat runs in (its conventions, names, decisions); "account": true of the user everywhere (language, formats, who they are). In a chat outside a project a note is always saved to the account.
note — one short line in the user's language, written the way they would jot it in their own notebook: the fact or preference alone, with no subject naming them ("the user", "пользователь", "they") and no mention of this chat or of being asked to remember. One fact per call; do not save what memory already holds.
